# 黑月科技

> [!IMPORTANT]
> 本项目已停止维护，后续开发已迁移至 [DaiMao204/MaaResonance](https://github.com/DaiMao204/MaaResonance)。
> 本仓库仅保留 NightChainsTech 历史源码、历史发布包和问题排查记录，不再接收新功能开发。
> 新版本下载、使用说明与问题反馈请前往 [MaaResonance Releases](https://github.com/DaiMao204/MaaResonance/releases) 和 [MaaResonance Issues](https://github.com/DaiMao204/MaaResonance/issues)。

雷索纳斯自动化辅助工具，当前维护版对原项目进行了重构，优化和新增了大量功能，同时大幅调整了UI界面。

本项目基于 [Night-stars-1/Auto_Resonance](https://github.com/Night-stars-1/Auto_Resonance) 继续维护和重构，保留了原项目许可和作者声明。

> [!WARNING]
> 最终维护版本为 `v0.2.5`。自动跑商、地图识别、账号配置读取和疲劳恢复仍可能受游戏 UI 更新影响；如需继续使用或反馈，请优先关注迁移后的 MaaResonance 项目。

## 主要变化

- 重构自动跑商配置界面，支持自动规划、手动双城、候选路线选择、单独配置去程和回程用书/抬砍。
- 接入与雷索纳斯 bot 对齐的商品、疲劳、声望、成员共振与综合参考利润计算，并修复买卖税率与附属城声望计算问题。
- 支持账号配置读取：智能读取货舱容量、城市声望、未解锁城市、商品未解锁状态和乘员共振，并在运行过程中持续更新。
- 支持疲劳恢复流程：喝酒、便当、体力药和桦石回体可按配置顺序处理，并记录/扣减可用次数。
- 优化交易所买卖、进货书使用、清空货柜、行情变动重试、商品解锁复查和路线重新规划逻辑。
- 优化地图导航和半路接管，加入城市坐标、锚点和状态识别，减少无效缩放、拖动和返回主界面。
- 增加实时运行状态显示：可以显示当前路线、候选路线、书量、抬砍、疲劳、利润和账号配置读取状态，并合并执行和停止按钮。
- 引入 GitHub Releases 自动更新。

## V0.2.5 更新要点

- 修复便当、喝酒、体力药或桦石已确认使用后，如果页面离开疲劳页且无法重新打开确认疲劳值，会被误判为恢复失败的问题；现在会按已恢复处理并交给后续交易流程复查。

## V0.2.4 更新要点

- 修复到站喝酒或疲劳检查后页面回到主地图时，后续买入/卖出流程仍按交易页继续执行导致失败的问题；现在会重新确认并恢复到目标买入/卖出页面。

## V0.2.3 更新要点

- 修复乘员仓库打开后未及时识别成功时，继续点击右上角入口偏移点导致误点“筛选”的问题。
- 乘员仓库页面识别改为综合判断“获取时间 / 稀有度 / 等级”、角色名、等级和星级信息，不再把单独的“筛选”文本当成有效页面依据。

## V0.2.2 更新要点

- 修复乘员配置读取在部分客户端未识别到“获取时间”排序控件时，可能误点到“筛选”的问题；现在无法确认排序控件时会跳过点击并继续扫描。

## V0.2.1 更新要点

- 修复乘员配置读取时“获取时间”排序点击点可能偏到“筛选”的问题；现在会优先点击排序箭头或文字左缘。
- 重新验证乘员仓库读取流程，完整扫描 `94/94` 乘员共振。

## V0.2.0 更新要点

- 新增规划参数中的未解锁城市列表；未解锁城市不会出现在自动规划城市列表中，脚本启动规划前会打开地图复查是否已解锁。
- 乘员配置支持 `未拥有`、`共振0` 到 `共振5` 的完整显示，识别结果按实际共振保存，计算时再折算为有效加成等级。
- 账号配置读取只补读缺失部分，支持从乘员仓库扫描乘员共振，并生成诊断图用于排查识别问题。
- 自动规划默认最大进货书调整为 6，默认货舱数量调整为 1136。
- 手动双城界面改为清晰显示去程和回程，并支持分别配置用书和抬砍。
- 疲劳恢复流程改为按喝酒、便当、体力药、桦石顺序处理；使用数量会随实际消耗自动递减。

## 下载与运行

> [!NOTE]
> NightChainsTech 的发布包仅作为历史版本保留。新版本请前往 [MaaResonance Releases](https://github.com/DaiMao204/MaaResonance/releases) 下载。

1. 如需使用旧版，前往 [历史 Releases](https://github.com/DaiMao204/NightChainsTech/releases) 下载 `NightChainsTech_<version>.zip`。
2. 解压到英文路径目录。
3. 运行 `黑月科技.exe`。

推荐模拟器：

- MuMu 模拟器
- 16:9 分辨率
- 推荐 `1920x1080` 或 `1280x720`

## 源码运行

需要 Python 3.11 或 3.12。

```powershell
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
python gui.py
```

## 自动更新

旧版软件内点击左侧底部 `更新`，仍只会检查 NightChainsTech 历史 GitHub Release，不会自动迁移到 MaaResonance。

发布完整包时建议同时在 Release 说明中写入 SHA256：

```text
SHA256: <64位sha256>
```
