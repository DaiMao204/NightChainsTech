## 新地图导航实现进展

- 新模块：`core/preset/map_navigation.py`
  - 进入/扫描逻辑：打开地图后先缩放到最小，可选择复位到西北边界，再按蛇形视口扫描。
  - 城市确认方式：点击候选图标后读取右侧城市信息面板标题；当前站点面板没有“前往目的地”时，也允许通过本地功能按钮判断面板已打开。
  - 候选点策略：地图主体基本都允许点击；只排除顶部按钮栏、右侧缩放控件、右下主线导航提示等明确 UI 禁点区。若地图文字 OCR 直接读到目标站名，会先尝试文字附近点击点。
  - 样本优先：扫描前会按 `resources/map/CityMapSamples2026.json` 中目标城市的历史样本点给候选排序，但最终仍以右侧面板标题为准。
  - 目标样本点会在通用彩色候选前优先验证；这只是减少试点数量，不能绕过右侧面板校验，因为同一屏幕坐标在不同视口状态下可能对应其他城市或无效区域。
  - 白色候选：白色标记包含大量不可点击路线/状态/装饰点，当前只在无点击标注工具里作为 `reference_only` 参考层显示，不参与自动点击。
  - 边缘处理：如果目标站名文字或推测点击点落在安全内区外，会先小幅拖动视口，把目标拉回内区后重新扫描同一视口。
  - 安全调用：`select_station_on_map(..., travel=False)` 只确认城市，不点击前往；`travel=True` 才会继续点击“前往目的地”。
  - 当前站点处理：`select_station_on_map(..., current_station="武林源")` 可在目标等于当前站时直接返回“已在目标站点”，不再强行点击地图上的当前站点箭头。
  - 地图刷新恢复：识别异常时，可通过 `refresh_station_map_from_map()` 执行“左上返回城市页 -> 右下启程重新进地图 -> 缩放到最小”，比在异常视口中继续盲扫更安全。
- 干跑工具：`tools/try_map_navigation.py`
  - 示例：`.\.venv\Scripts\python.exe tools\try_map_navigation.py 栖羽站 --no-reset --rows 1 --columns 1 --limit 18`
  - 当前站点示例：`.\.venv\Scripts\python.exe tools\try_map_navigation.py 武林源 --current-station 武林源 --no-reset`
  - 刷新地图示例：`.\.venv\Scripts\python.exe tools\try_map_navigation.py 栖羽站 --refresh-map --no-reset --rows 1 --columns 1`
  - 失败后刷新重试示例：`.\.venv\Scripts\python.exe tools\try_map_navigation.py 栖羽站 --retry-refresh --no-reset`
  - 已验证：`栖羽站`、`云岫桥基地`、`岚心城` 可在当前视口安全确认，其中 `岚心城` 带未开启/红色状态提示仍可通过右侧面板确认。
  - 已验证：目标等于当前站点时，`武林源 --current-station 武林源` 会直接返回“已在目标站点”，不扫描地图、不点击前往。
  - 已验证失败场景：目标不在当前视口时会返回“未找到目标站点”，不会点击前往按钮；收紧普通候选点击后，单视口失败耗时约 35 秒。
- 探测工具同步：`tools/probe_visible_map_cities.py`
  - 已改为读取 `resources/map/CityMapSamples2026.json` 中的新城市名。
  - 遮罩已从“整块屏蔽右侧”改为禁点区模型：顶部按钮栏、右侧缩放控件、右下主线导航提示不点击，其余地图主体可作为候选。
- 无点击标注工具：`tools/annotate_map_candidates.py`
  - 只生成截图标注和 JSON，不点击、不拖动。
  - 输出示例：`diagnostics/candidate_overlays/wulin_sample_priority.png`
  - 蓝色 `S*` 为目标城市历史样本点，黄色 `C*` 为彩色候选，白色候选默认隐藏且只作为参考层。
  - 用于让人工确认候选点、缩放禁区、主线提示禁区、目标样本点后，再调整 live 点击规则。
- 当前限制：
  - 还没有把新版导航接入旧的 `click_station` 主流程，先保持在干跑工具里验证。
  - 尚未真实点击“前往目的地”跑完整移动流程。
  - 逐点点击扫描做大范围搜索仍然太慢，`rows=2` 的失败场景曾超过 4 分钟；后续应优先做“视口定位 + 样本/世界坐标优先候选”，而不是盲目增加扫描行列。
  - 当前站点白色箭头可以打开城市面板，但白色检测噪声很大；未来若要支持它，必须先基于人工标注的有效箭头热区做专门检测，不能把所有白色候选都当可点击点。

5. 用离线截图做回放测试。
